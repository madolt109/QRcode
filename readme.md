# 🔳 Gerador de QR Code para E-commerce

## 🚀 Sobre o Projeto
<p>
Este projeto é um gerador de <strong>QR Codes</strong> desenvolvido com 
<strong>Node.js</strong>, criado durante estudos da plataforma DIO.
</p>

<p>
A aplicação funciona como um kit de utilidades para e-commerces,
permitindo gerar QR Codes diretamente pelo terminal de forma simples e rápida.
</p>

## ⚙️ Funcionalidades
<ul>
  <li>Gerar QR Codes no terminal</li>
  <li>Entrada de dados personalizada</li>
  <li>Execução via linha de comando</li>
  <li>Estrutura modular e escalável</li>
</ul>

## 🧠 Tecnologias Utilizadas
<ul>
  <li>Node.js</li>
  <li>JavaScript</li>
  <li>qrcode-terminal</li>
  <li>chalk</li>
  <li>prompt</li>
</ul>

## 📥 Instalação

<pre>
git clone https://github.com/seu-usuario/projeto-qrcode.git
cd projeto-qrcode
npm install
</pre>

<pre>

</pre>
